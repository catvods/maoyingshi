# Bundled fonts

Two font files live in this directory, bundled so the ported
themes' `titleFont` design parameter renders with real fonts:

- `NotoSerifSC.ttf` — family `NotoSerifSC` (titleFont: serif).
  Noto Serif SC, by Google / Adobe. Licensed under the SIL Open
  Font License, Version 1.1 (the license text is embedded in the
  font's name table, name ID 13).
- `LXGWWenKaiLite-Regular.ttf` — family `LXGWWenKaiLite`
  (titleFont: wenkai). LXGW WenKai Lite （霞鹜文楷轻便版）, by
  LXGW. Licensed under the SIL Open Font License, Version 1.1
  (license text likewise embedded in the font, name ID 13).

Both files are the same files LeeCatVodSimplify ships in its own
assets (extracted from its release APK, 2026-11-25 download),
registered under the same family names its FontManifest uses.
The SIL Open Font License permits bundling and redistribution
with the license retained; this note is that retention.
